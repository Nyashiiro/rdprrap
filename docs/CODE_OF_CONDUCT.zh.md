# Contributor Covenant 行为准则

[English](../CODE_OF_CONDUCT.md) | [한국어](CODE_OF_CONDUCT.ko.md) | **中文**

## 我们的承诺

作为成员、贡献者与维护者，我们承诺：无论年龄、体型、可见或不可见的残障、族裔、性征、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、外貌、种族、宗教或性身份与性取向如何，都让每个人在这份社区中的参与免受骚扰。

我们承诺以有助于建设开放、欢迎、多元、包容且健康的社区的方式行事与互动。

## 我们的标准

有助于营造积极环境的行为示例：

- 展现同理心与善意
- 尊重不同的意见与经历
- 给予建设性反馈，并得体地接受
- 为错误承担责任并从中学习
- 以对整个社区最有利的事为重

不可接受的行为示例：

- 性化的语言、图像或关注
- 恶意引战、侮辱或贬损性评论
- 公开或私下的骚扰
- 未经许可公开他人的隐私信息
- 其他不适合职业场合的行为

## 执行责任

项目维护者有责任澄清并执行可接受行为的标准，并在必要时采取公正的纠正措施。

## 适用范围

本行为准则适用于项目内的所有空间，也适用于任何人正式代表项目出现在公开空间的场合。

## 执行与举报

发现不可接受的行为，请向维护者举报：非敏感事项可通过仓库的 Discussions 或 Issues 反映；敏感举报请使用仓库主页所列的私下联系渠道。

所有投诉都会得到及时、公正的审查与调查。

## 执行准则

社区影响分级准则改编自 Contributor Covenant，可能包括：

1. 纠正
2. 警告
3. 临时封禁
4. 永久封禁
